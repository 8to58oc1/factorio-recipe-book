## 📖 About

🔹 **Factorio — Recipe Book** is a powerful tool built to help you browse all Factorio recipes, technologies, and production chains in an in-game searchable reference. No more alt-tabbing to the wiki — Recipe Book puts complete crafting and machine information right in the game.

🔸 Whether you're a seasoned professional or just getting started, **Factorio — Recipe Book** delivers a clean, intuitive experience packed with everything you need — right out of the box. Join thousands of users who've already streamlined their Factorio modding workflow. Download now and get started in minutes. 🚀

## 🚀 Features

| Feature | Description |
|---------|-------------|
| Recipe Browser | Search and browse all unlocked and upcoming recipes in-game |
| Technology Tree | Visual reference for research requirements and unlock chains |
| Production Calculator | Calculate input requirements for target production rates |
| Mod Aware | Automatically includes all recipes from installed mods |
